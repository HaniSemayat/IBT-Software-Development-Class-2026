# Validated Persistent Signup Form

A simple signup form that validates an Ethiopian name and phone number, then saves valid signups in the browser using `localStorage`.

## Features

* Validates full name
* Validates Ethiopian phone numbers (`09...` and `+251...`)
* Displays clear error messages
* Saves valid signups to `localStorage`
* Restores saved signups after refreshing the page
* Handles missing or corrupted saved data safely

## Technologies

* HTML
* CSS
* JavaScript
* LocalStorage
