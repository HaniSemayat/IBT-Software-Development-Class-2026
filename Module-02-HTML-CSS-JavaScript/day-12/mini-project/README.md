# Habesha Eatery Mini Site

A simple two-page restaurant website built with semantic HTML as part of the CodeOps Module 2 Day 12 assignment.

## How to Open

1. Open `index.html` in a web browser.
2. Use the navigation links to move between the Reservations and Contact pages.

## Accessibility Features

- Semantic HTML (`header`, `nav`, `main`, `section`, `footer`)
- One `<h1>` on each page
- Proper `<label>` elements for every form control
- Tables include `<caption>`, `<thead>`, `<tbody>`, and `scope` attributes
- Images include descriptive `alt` text
- Embedded map includes a descriptive `title`
- Keyboard-friendly navigation using standard links and buttons
