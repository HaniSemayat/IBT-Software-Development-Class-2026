# Bole Brew Café

A fictional business profile card for a café in Bole, Addis Ababa.

## CSS Techniques Used

- CSS custom properties
- `:root`
- `var()`
- Box model
- `box-sizing: border-box`
- Google Fonts
- HSL colors
- Hover states
- Pseudo-elements
- CSS specificity
- Typography hierarchy
- Responsive layout
