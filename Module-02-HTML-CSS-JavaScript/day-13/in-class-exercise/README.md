# Habesha Eatery Menu Card

A styled menu card created as part of Module 2, Day 12 CSS practice.

## Files

- `starter.html` — HTML structure for the menu card.
- `styles.css` — CSS styling for the component.

## How to Open

Open `starter.html` in a web browser.

## Requirements Completed

- Added `box-sizing: border-box` to the global reset.
- Set a base font family and line height on `body`.
- Added padding to the menu card.
- Added a border to the menu card.
- Added a gold top accent.
- Used CSS variables with `var()` for colors.
- Added typography styling.
- Added a `:hover` pseudo-class.
- Added a `::before` pseudo-element to prefix the price with "ETB ".
- Used `:nth-child(even)` to create zebra striping for the ingredient list.
