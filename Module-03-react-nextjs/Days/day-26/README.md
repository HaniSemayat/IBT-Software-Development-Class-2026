# Addis Eats - React

Addis Eats is a static food menu rebuilt with React as part of my Software Development training.

This is the React project for the **Module 2 React lessons**, focusing on React setup, JSX, components, props, arrays, `map()`, and keys.

## Features

- Static Addis Eats menu
- Reusable Dish component
- Header component
- Menu rendered from an array
- Dynamic dish names and prices using props

## Technologies

- React
- Vite
- JavaScript
- JSX

## How to Run

Install the dependencies:

```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Then open the local URL provided by Vite.

What I Practiced

This project helped me practice creating React components, passing props, writing JSX, rendering arrays with map(), and using unique keys.
