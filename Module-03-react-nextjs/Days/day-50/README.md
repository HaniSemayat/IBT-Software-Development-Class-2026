# Day 50 — Capstone Project Presentation

## Overview

Day 50 marked the presentation of **Sheggar Wheels**, a peer-to-peer car rental platform developed as the full-stack capstone project during the IBT–QIYAS Advanced Digital Skills Training Program.

The session focused on showcasing the completed application, demonstrating its core functionality, and explaining the technical decisions and development process behind the project.

## Key Activities

- Presented the Sheggar Wheels capstone project.
- Demonstrated the application's core features and user workflows.
- Explained the project architecture, technologies, and implementation.
- Highlighted the problems addressed and the value delivered by the platform.
- Shared the development experience, challenges, and key takeaways.

## Outcome

Successfully showcased the capstone project, bringing the development and refinement phase to its presentation milestone.
