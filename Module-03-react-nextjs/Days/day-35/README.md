# Day 35 Project

## Addis Eats — React Project

This day's project is **Addis Eats**, a React frontend for a food-ordering application in Addis Ababa.

Instead of keeping the project inside the daily module repository, I will build it in a **separate repository** called **Addis-Eats**.

The project will bring together the React concepts and features covered from **Day 26 onward** into one finished application.

### Project Repository

**Repository:** `Addis-Eats`

### Main Technologies

* React
* React Router
* JavaScript
* CSS
* Zustand
* Vite

### Purpose

The goal of this project is to combine the React concepts learned throughout Module 3 into a complete, structured, and functional application.
